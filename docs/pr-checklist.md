# Lista de comprobación de PR

Para todo PR que toque `src/md/` o sus pruebas (spec 008, RF-7.1).

- [ ] Declaro que el cambio no contiene código de oráculos (gpgx, ClownMDEmu, ares): sin código de oráculos.
- [ ] Las fuentes del cambio son documentación de hardware, ROM de prueba u observación de caja negra.
- [ ] Quien lo escribe no figura en `docs/clean-room-register.md` para este componente.
- [ ] Las dependencias nuevas no son copyleft (GPL, LGPL, AGPL) y están en `legal/DEPENDENCIES.csv`.
