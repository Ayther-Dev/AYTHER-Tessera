## Estado completo
Todo el estado está en la estructura `z80_t`, de datos planos: pasos del decodificador, latch, opcode, pins, bits de interrupción, registros, sombra, `im`, `iff1`, `iff2`. Un savestate puede copiar la estructura byte a byte (con orden de campos fijo, no memcpy portable) sin ganchos adicionales.

## Temporización
`z80_tick(cpu, pins)` avanza un ciclo T y devuelve el estado de los pins, de modo que el bus y los estados de espera (`Z80_WAIT`) los gestiona el llamante ciclo a ciclo. Es el modelo que necesita el arbitraje del bus de la MD.

## Nota de compilación
Las uniones con estructuras anónimas son C válido pero no C++ (lo avisa el propio header): se compila como archivo C y se expone a través de una función envoltorio.
